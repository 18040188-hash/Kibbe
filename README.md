# VÉNUS — App de estilismo Gen Z

Landing page de VÉNUS, una app de estilismo que combina Kibbe, colorimetría y astrología para crear una identidad visual personalizada.

## Ejecutar localmente

Abre `index.html` en el navegador.

## Tecnologías

- HTML
- CSS
- JavaScript
- Google Fonts
- Imágenes de Unsplash

## Concepto

VÉNUS no busca asignarte una estética genérica. Cruza estructura corporal, paleta de color y elementos de astrología para construir una identidad visual propia.
